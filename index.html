Comment fonctionnera DealPiixs ?

Nous sélectionnerons des offres vérifiées auprès de boutiques partenaires. Certains liens pourront être affiliés : si vous achetez via ces liens, le site pourra recevoir une commission. Les achats seront réalisés directement chez les marchands.

Version actuelle : prototype gratuit sans liens d'achat, sans inscription et sans collecte d'e-mails. Les favoris sont enregistrés uniquement dans ce navigateur.
